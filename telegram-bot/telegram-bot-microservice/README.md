# Telegram-бот

При отправке видео бот отвечает на исходное сообщение двумя значениями:
`file_id` и `file_unique_id`. Они оформлены моноширинным текстом для копирования.

Поддерживаются сообщения Telegram типа video, включая пересланные видео.
Видео, отправленное как документ, этим обработчиком не обрабатывается.
Существующее обновление file_id по file_unique_id в сервисе сохраняется.
Ответ с ID отправляется до обновления; ошибка обновления не отменяет ответ.
