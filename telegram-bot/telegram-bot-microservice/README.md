# Telegram-бот

При отправке видео администратором в личном чате бот отвечает на исходное
сообщение именем файла, `file_id` и `file_unique_id`. Они оформлены
моноширинным текстом для копирования; если Telegram не передал имя, указано
«не указано». Обычным пользователям и в групповых чатах ответ с ID не отправляется.

Поддерживаются сообщения Telegram типа video, включая пересланные видео.
Видео, отправленное как документ, этим обработчиком не обрабатывается.
Существующее обновление file_id по file_unique_id в сервисе сохраняется.
Ошибка обновления не отменяет ответ с ID.

Администратор может заменить существующее видео серии, отправив его в личный
чат бота. Первый подходящий трёхзначный код в имени обозначает серию:
`704` означает сезон 7, серию 4. Качество определяется по высоте видео, переданной Telegram:
1080 — `Full HD`, 480 — `SD`. Высоты другого размера пока не поддерживаются.
Существующие подписи `FullHD`/`1080p` и `SD`/`480p` сопоставляются с
этими качествами. Обозначения вроде `480p` и кодеки вроде `x264` не считаются
кодом серии. Если по первому коду не найдена ровно одна серия, либо качество
неоднозначно, изменения не вносятся; следующие коды не проверяются.
Если подходящий вариант качества уже есть, бот заменяет его ID и метаданные.
Если варианта нет, бот добавляет его в серию и сообщает об этом. Новый `SD`
получает приоритет выше других доступных вариантов, а новый `Full HD` — ниже
доступного `SD`, чтобы по умолчанию воспроизводилось `SD`.
Если Telegram не передал все метаданные, видео не заменяется и не добавляется.
В ответе указывается результат.
